# `frontend/` (Raiz do Frontend Web)

Esta pasta representa a **raiz do frontend web** no monorepo.

## Atenção (estado atual do repositório)

No estado atual, o código do frontend web está em `TitanSystem/frontend/`.

Esta pasta existe para cumprir a separação **na raiz** e manter a arquitetura clara.

## Como isso se conecta ao sistema

- O frontend web consome a API do backend via HTTP.
- Ele também serve como base de interface para o aplicativo de computador (Electron).

## O que deve morar aqui (próximo passo de organização)

- Em uma limpeza de repositório, o conteúdo de `TitanSystem/frontend/` deve ser movido para `frontend/` preservando histórico.
- A base de estilo do design “Vibe Code” (Tailwind + Shadcn UI + modo claro/escuro) será montada aqui.
