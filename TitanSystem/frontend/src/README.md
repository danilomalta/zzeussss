# `src/` (Aplicação React)

Código-fonte do frontend web.

## Como se conecta ao sistema

- Consome o backend em `TitanSystem/backend` via HTTP.
- Compartilha a base de UI/fluxos com o Desktop (Electron).

## Subpastas

- **`components/`**: componentes reutilizáveis (UI e blocos de feature).
- **`pages/`**: páginas/rotas (telas) do app.
- **`lib/`**: utilitários, clientes HTTP, helpers e integrações.
- **`hooks/`**: hooks React reutilizáveis.
- **`styles/`**: estilos globais e tokens (enquanto o Tailwind/Shadcn não estiverem configurados).
