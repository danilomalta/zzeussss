# `lib/` (Bibliotecas e integrações)

Código de suporte reutilizável que não é componente React.

## O que deve ser programado aqui

- Cliente HTTP (ex.: wrapper de `fetch`/`axios`)
- Helpers de formatação (moeda, datas, máscaras)
- Integrações (ex.: impressão, leitores, etc.) quando aplicável ao web/desktop
