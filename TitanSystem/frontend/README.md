# Frontend Web (React + TypeScript + Vite)

Este diretório contém o **frontend web** do TitanSystem.

## Objetivo

- Fornecer a interface de PDV (catálogo, carrinho, pedidos, relatórios básicos).
- Consumir a API do backend via HTTP.
- Servir de base para o Desktop (Electron), reutilizando UI e fluxos.

## Pastas principais

- **`public/`**: arquivos estáticos servidos pelo Vite.
- **`src/`**: código-fonte React/TypeScript.

## O que deve ser programado aqui

- Layouts, páginas e componentes reutilizáveis do PDV.
- Configuração de tema (dark/light) e design system (Tailwind + Shadcn UI) no PASSO seguinte.
