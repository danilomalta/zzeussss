# Desktop (Electron)

Este diretório contém a aplicação Desktop do TitanSystem usando **Electron**.

## Objetivo

- Executar o sistema em Windows/Linux/macOS com empacotamento nativo.
- Reutilizar o frontend web como UI principal (mesmos componentes e páginas).

## O que deve ser programado aqui

- Processo principal do Electron (janela, atualizações, permissões).
- Preload/bridge (quando necessário) para expor APIs nativas ao frontend com segurança.
- Configuração de build/distribuição.
