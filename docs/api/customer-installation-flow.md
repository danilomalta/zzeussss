# Roteiro do cliente — homologação (fase 5)

Entrada da interface: `/local/company`, somente proprietário autenticado. Não é endpoint de inicialização pública nem conta do fornecedor. O roteiro usa exclusivamente a revisão retornada pelo contrato `company-registration.openapi.json` para exibir pré-cadastro/cadastro central salvos; edição ainda não persistida nunca conclui etapa.

1. Instalar na infraestrutura escolhida pelo cliente. `titan-local init`/instalador existente inicializam apenas caminhos novos; não executar numa instalação existente. O `--db` de `serve` define o arquivo local ao host escolhido. `deployment.Profile` valida local/servidor/nuvem do cliente; HTTPS/TLS e redes permitidas são configuração privada. `titan-local mode --deployment PERFIL_ABSOLUTO` só descreve o perfil, não migra dados nem inicia serviços.
2. No terminal privado do cliente, usar os comandos existentes `titan-fiscal vault-init`, `vault-export-key` e `vault-rotate`, com caminhos privados explícitos. A tela oferece instruções, nunca recebe/executa chaves. Recuperação usa uma cópia consistente do cofre e a chave correspondente; backups antigos mantêm suas chaves. Sem chave correspondente, não há recuperação pelo fornecedor.
3. Ler/salvar o cadastro via `GET/POST /local/v1/company/registration`, sem fonte automática de CNPJ. Somente revisão persistida compõe o progresso. Não contrata módulos nem concede autorização fiscal.
4. Abrir `/local/enterprise?area=fiscal`, criar o perfil manual e reencontrá-lo via `GET /local/v1/fiscal/profiles?limit=20[&after=ID]`. O cadastro privado do provedor precisa estar habilitado pelo cliente na instalação. `GET/POST /local/v1/fiscal/onboarding/:id/provider` preservam as mesmas permissões, cofre e recuperação existentes; nunca devolvem token/CSC. A1/CSC/emitente na conta Focus e teste real continuam externos. Diagnóstico local não é aceite da Focus/SEFAZ.
5. Funcionários ficam em `/local/staff`, usando `GET/POST /local/v1/staff`, módulos e permissões existentes. O roteiro não aumenta privilégios; emissão NF-e 55 segue exclusiva do proprietário, sessão e contrato fiscal ativos.

Nenhuma rota HTTP nova nesta unidade C2. Não há fetch externo, telemetria, armazenamento de cadastro/chave no navegador nem execução de comandos por IPC neste roteiro. Produção fiscal e controles existentes permanecem intactos. As instruções são apresentadas nos cinco idiomas da interface.
