# Evidências do incremento fiscal

`verification.json` associa a base, sequência, resultados, limites e hashes de
fontes e logs. `full.log` é a execução integral aprovada. `applied-specific.log`
inclui o novo perfil de homologação e o detector de corrida. Os demais arquivos
registram as verificações estáticas, build, contratos e módulos. Logs de testes
sintéticos, sem bancos, certificados, chaves privadas ou tokens reais.

PASS do caso de incompatibilidade de produção prova a recusa segura; PASS da
DPS de homologação prova geração/assinatura local com certificado sintético.
Nenhum deles prova autorização ou homologação em serviço oficial.
