# Referência do PDV desktop

O PDV ativo está em `../../../frontend-web/src/modules/pos/`, exibido pelo Electron. Não há segunda implementação de vendas nesta pasta.

IndexedDB/localStorage preservam rascunhos e tentativas da interface; não autorizam venda comercial offline por si só. Sem serviço operacional ou direito exclusivo previamente obtido, não oferecer sucesso fictício, reenvio automático ou venda sobre estoque global cacheado.

Internet e rede local são conexões distintas. O modo de conexão não cria cotas de estoque, sincronização P2P ou banco independente por aparelho. Esses contratos permanecem sujeitos à validação do backend e do dispositivo.
