# `desktop/` (Raiz do Aplicativo de Computador)

Esta pasta representa a **raiz do aplicativo de computador** do monorepo (Electron).

## Atenção (estado atual do repositório)

No estado atual, o código do aplicativo de computador está em `TitanSystem/desktop/`.

Esta pasta existe para cumprir a separação **na raiz** e manter a arquitetura evidente.

## Como isso se conecta ao sistema

- O Electron empacota a interface do frontend web.
- Ele consome a API do backend via HTTP, assim como o web.

## O que deve morar aqui (próximo passo de organização)

- Em uma limpeza de repositório, o conteúdo de `TitanSystem/desktop/` deve ser movido para `desktop/` preservando histórico.
