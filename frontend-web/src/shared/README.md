# FSD Shared Layer

Esta pasta (`src/shared/`) contém recursos reutilizáveis e agnósticos a qualquer domínio específico da aplicação:
- `components/`: Componentes visuais globais (ex: Header, Sidebar, inputs customizados, modais genéricos).
- `utils/`: Funções utilitárias puras (ex: formatação de moeda, data, validações).
- `types/`: Tipagens TypeScript globais (DTOs compartilhados com o Backend).
